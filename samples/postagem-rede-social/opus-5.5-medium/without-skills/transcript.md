- Modelo: `opus-5.5-medium`

## Usuário, turno 1

Escreve uma postagem pro LinkedIn contando que publiquei como código aberto a minha coleção de skills em português para agentes de código (Claude Code e Codex). Elas cobrem especificar, implementar, revisar e verificar o trabalho, e o agente só age com autorização explícita. O repositório é github.com/jordyfontoura/skills. Quero que desenvolvedores brasileiros testem e mandem sugestões.

## Agente, turno 1

Aqui vai uma proposta:

---

**Publiquei como código aberto minha coleção de skills em português para agentes de código 🇧🇷**

Uso agentes como o Claude Code e o Codex todos os dias. Quase todo o material sobre como orientá-los está em inglês. Por isso juntei as skills que uso no meu dia a dia, escritas em português, e abri o repositório para a comunidade.

As skills cobrem o ciclo completo de uma tarefa:

🔹 **Especificar**: deixar claro o que precisa ser feito antes de escrever qualquer linha de código
🔹 **Implementar**: executar o plano de forma organizada
🔹 **Revisar**: olhar o resultado com atenção, procurando problemas
🔹 **Verificar**: confirmar que o trabalho realmente funciona

Um princípio guia todas elas: **o agente só age com sua autorização explícita.** Ele propõe, explica e espera seu "pode seguir". Você continua no controle do que acontece no seu código.

O projeto ainda está crescendo e quero melhorá-lo com a ajuda de quem usa essas ferramentas de verdade. Se você é dev e usa agentes de código, testa e me conta:

✅ O que funcionou bem
🛠️ O que pode melhorar
💡 Que skill está faltando
